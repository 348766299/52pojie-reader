吾爱阅读

一个专门解决「在手机上看吾爱破解论坛不方便」的安卓客户端。保留原站全部功能，只把「看」这件事做好。

为什么不直接照抄 GitHub 上的 LCG

GitHub 上最成熟的是 fabricezhang/lcg（807★）和续作 sjshb57/NewLcgR（v2.3.0）。它们是 Jsoup 抓取 + 原生渲染，体验原生，但要自己维护登录态、formhash 和 Discuz 页面解析。

续作 README 里作者写着「坏了，有没有人提交代码诶，我不会修」——这正是抓取型客户端的维护代价。

本项目的取舍：用 WebView 承载原站（登录 / 签到 / 回复 / 附件天然可用），注入 CSS + JS 专做移动端阅读增强。站点改版时改几个选择器就能恢复；最坏情况下它只是个带工具栏的浏览器，不会整体不可用。

Features / 功能

01

优化排版

Discuz 左右两栏表格改单栏，正文全宽、图片自适应、代码块横向滚动。

02

沉浸阅读

只留标题与楼层正文，重排成卡片；支持只看楼主。

03

恢复缩放

原站写死 user-scalable=no，App 注入修正，双指可放大 5 倍。

04

夜间 + 字号

跟随系统或手动切换，字号 80%~160% 可调并持久化。

05

链接提取

一键列出正文里的网盘 / 附件链接，单条或全部复制。

06

大图查看

点图片全屏查看，双指缩放、左右翻页、外部打开。

07

收藏与历史

本地 JSON 存储，长按删除；不上传、不联网。

08

零依赖

不用 AndroidX / OkHttp / Jsoup，无统计 SDK，构建更快更稳。

Get the APK / 拿安装包

三种方式，推荐第一种

方式 A · 推荐
GitHub Actions 云端打包

把整个目录推到新建的 GitHub 仓库，Actions 自动构建。跑完下载 wuai-reader-apk 产物即可安装。不用装 Android Studio。

方式 B
Android Studio 本地编译

装 Android Studio（自带 JDK 17）+ API 34 / Build-Tools 34，打开目录后 Build APK；命令行用 gradlew.bat assembleDebug。

方式 C
只想马上有得用

直接装现成开源客户端 NewLcgR v2.3.0 或 LCG V1.8.7（非本项目），Releases 页有 APK。

当前这台电脑没有 JDK / Gradle / Android SDK，所以交付的是可直接编译的完整源码 + 自动打包工作流，而不是现成 APK。工作流已配好 workflow_dispatch，改完代码手动触发即可重新打包。
